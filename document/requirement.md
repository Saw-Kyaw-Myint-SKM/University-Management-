# University Management System Requirements

## Project Overview

Build a modern University Management System using:

- Laravel 9
- PHP 8+
- MySQL
- TailwindCSS
- Alpine.js

The system should support:

- Admin Panel
- Teacher Panel
- Student Panel
- Admission System
- Enrollment System
- Attendance System
- Examination System
- Result Management
- Notifications

---

# Functional Requirements

## Authentication Module

### Features

- Login

- Email Verification
- Role-Based Access Control

### Roles

- Admin

- Student

# Admin Requirements

Admin can:

- Manage faculties
- Manage departments
- Manage courses
- Manage teachers
- Manage students
- Manage admissions
- Approve enrollments
- Manage exams
- Publish results
- Configure settings
